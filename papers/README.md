# Manuscript archive

Expected versioned manuscript locations are recorded in [the publication inventory](../docs/PUBLICATION_STATUS.md). Original PDF and Word binaries are transferred separately; this file is not evidence of their presence.

Keep each paper independent. Preserve earlier versions as historical research artifacts and record SHA-256 checksums. The master index does not replace the paper-specific data and code repositories.

All manuscripts are unreviewed working drafts or preprint candidates.
