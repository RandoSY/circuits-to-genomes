# Paper 3 v0.4 — local review package

This package is an unreviewed working manuscript, not a release promoted on GitHub. It integrates the two v0.3 drafts and the investigator's instruction to preserve the reciprocal computing–biology question. The return direction is proposed, not verified. No new scientific computations or literature audit were conducted.

The PDF is rendered by build.py from manuscript.md and the vector diagrams defined in that script. The SVG files are included as illustration assets. To reproduce on Linux, install Python reportlab and the DejaVu Sans fonts; run python build.py from the source folder. The renderer writes the PDF to the parent directory. The original v0.2 and both v0.3 drafts should be preserved independently.
