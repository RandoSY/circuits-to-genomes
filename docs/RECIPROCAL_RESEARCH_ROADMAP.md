# C2G: reciprocal research and validation roadmap

26 November 2026 — coordinated review release. This roadmap supersedes earlier proposed editorial insertions, not any experimental data.

| Research gate | Deliverable | Falsifier / limit |
|---|---|---|
| Engineering replication | Independent CPU reproduction of both Boolean and matrix pilots, code audit; report event strata and worst case | Model or result mismatch; no pooling of incompatible workloads |
| Native accelerator measurement | Use portable GPU baseline first, then device-specific CUDA profiling; exact correctness, timings, memory traffic and validated energy where available | No measured H100 behavior until hardware execution; record device/configuration |
| Return transfer | Compare bio-inspired complementary design, matched effective resource budget, full duplication and established ABFT/checksum methods | No improvement on holdout or failure after coordinator/common-source faults |
| Biological transfer (H3-D) | Specialist-approved prospective endogenous perturbation protocol, validated links, overlap profiles and prespecified outcome | No fit-for-purpose dataset yet; null or opposite prediction preserved |
| Research-process evaluation | Claim dependency ledger and blinded prospective matched review tasks | No claim of AI error correlation or classroom benefit from the hardware models |
| Publication | Qualified biostatistics, genomics, architecture and metascience review; obtain author approval; integrate revision sections into final journal manuscript | Preserve negative results and all uncertainty |

[Coordinated review release](../research/coordinated-revision/2026-11-26/START_HERE.md). [H100 Boolean experiment](../research/h100-lab/v0.1/FINDINGS.md). [Hopper matrix experiment](../research/hopper-pilot/v0.2/README.md). [Validation protocol](VALIDATION.md).

The organizing question is reciprocal: computing informs biology; biological observations motivate computing tests; their outcomes generate new questions in both fields. Do not equate a testable return experiment with a demonstrated biological-to-engineering innovation.
